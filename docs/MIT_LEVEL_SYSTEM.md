# 🎓 MIT 水平评级系统详细文档

## 设计理念

本系统基于 MIT 实际课程编号体系和培养方案，将用户在各门课程中的掌握度转化为"MIT 学术等级"。目标是让用户清晰知道：

1. 我现在大概相当于 MIT 的什么水平？
2. 我离下一个级别还差多少？
3. 如果学完所有课，最高能达到什么级别？

阈值基于 MIT 实际培养方案的学分要求：

- **大一（220）**：约等于完全掌握 1 门满分入门课（如 14.01 = 360 含金量，60% 掌握 ≈ 220）

- **正教授（2500）**：需要完全掌握所有 9 门课且达到高掌握度

## 含金量计算公式

### 单课含金量

```
满分含金量 = 难度 × 学分 × 10
实际含金量 = 满分含金量 × 掌握度 × (0.5 + 0.5 × 覆盖率)

其中：
  掌握度 = 该课所有知识点的平均 mastery level / 5 × 100%
  覆盖率 = 已掌握知识点数(level>=3) / 总知识点数
```

**设计说明**：
- `0.5 + 0.5 × 覆盖率` 意味着即使掌握度 100%，但如果只学了部分知识点，含金量也要打折
- 覆盖率 100% 时系数 = 1.0，覆盖率 50% 时系数 = 0.75，覆盖率 0% 时系数 = 0.5

### 总含金量

```
总含金量 = Σ(每门课的实际含金量)
```

### 等级映射

遍历 13 级等级轴，找到 `总含金量 >= level.min` 的最高等级。

## 3 种进度条

### 1. 当前等级 → 下一等级
- 显示从当前等级到下一等级的进度
- 计算公式：`(总含金量 - 当前等级min) / (下一等级max - 当前等级min) × 100%`
- 用途：知道还差多少含金量到下一级

### 2. 在 MIT 等级轴上的位置
- 显示在整个等级轴（附中 → 教授）上的位置
- 计算公式：`总含金量 / 2500 × 100%`
- 用途：纵观全局，知道自己在哪里

### 3. 所有课程含金量上限
- 显示如果完全掌握所有课程，最高能达到的位置
- 计算公式：`总满分含金量 / 2500 × 100%`
- 用途：知道当前课程库的天花板在哪

### 等级轴可视化

等级轴是一条彩色渐变线，从灰色（附中）到金色（教授），上面标注两个点：
- **当前位置**：圆点 + 等级名称
- **课程上限**：紫色虚点（如果高于当前位置）

## 速度评价

基于"平均每门课含金量"和"平均掌握度"计算：

| 评级 | 条件 | 说明 |
|------|------|------|
| S+ 降维打击 | 平均含金量≥400, 掌握度≥80% | 学习极快，远超常人 |
| S 顶级天才 | 平均含金量≥300, 掌握度≥70% | 远超 MIT 平均水平 |
| A 卓越 | 平均含金量≥200, 掌握度≥55% | 比 MIT 大部分学生快 |
| B 优秀 | 平均含金量≥120, 掌握度≥40% | 与 MIT 优秀本科生相当 |
| C 中等 | 平均含金量≥60, 掌握度≥20% | 与 MIT 普通本科生相当 |
| D 起步 | 平均含金量>0 | 刚开始学习 |

## 扩展指南

### 添加新课程到评级系统

1. 在 `COURSE_DATABASE` 中添加课程元数据：
```javascript
'new-course-id': {
  name: '课程名称',
  mit_equiv: 'MIT编号',
  level: 'ug-freshman',  // 参考已有课程
  difficulty: 5,           // 1-10
  credits: 12,             // MIT学分制
  category: 'economics',   // economics | cs | media
  note: '课程说明'
}
```

2. 难度评分参考 MIT 课程编号体系
3. 如果课程不是 MIT 的，设为 `mit_equiv: null`

### 修改等级阈值

修改 `LEVELS` 数组中每个等级的 `min` 和 `max` 值。注意保持单调递增。

### 修改含金量公式

修改 `Calculator.calculateCourseValue()` 中的公式。注意：
- 修改后所有课程的含金量都会变化
- 等级阈值可能需要相应调整
- 建议修改后在控制台测试：`MITLevelSystem.Calculator.calculateTotal(MITLevelSystem.Controller.getCourseData())`
