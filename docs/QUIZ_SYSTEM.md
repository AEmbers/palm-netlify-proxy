# 🧪 测验系统详细文档

## 题库生成引擎（QuestionGenerator）

### 题型与变形策略

#### 单选题（Single Choice）
每个知识点生成 3-5 个变形题，通过以下策略变形：

| 变形方式 | 说明 | 示例 |
|---------|------|------|
| 正向定义 | 直接问知识点定义 | "ROI 是什么？" → 选正确定义 |
| 反向选择 | 给定义选术语 | "投资回报比的术语是？" → 选 ROI |
| 错误表述 | 判断哪个选项错误 | "以下关于 ROI 的说法哪个是错误的？" |
| 场景应用 | 给场景选适用知识点 | "投1000元卖5000元，ROI 是多少？" → 选 5 |
| 关键词替换 | 替换关键词制造干扰项 | 原词"转化"替换为"留存"等 |

**干扰项生成**：使用确定性种子随机（基于知识点文本哈希），确保同一知识点始终生成相同的错误选项，保证题目一致性。

#### 多选题（Multiple Choice）
- 从同一课时中选 2-4 个相关知识点
- 问"以下哪些是正确的"
- 正确选项 1-3 个，错误干扰项 2-3 个

#### 判断题（True/False）
- 将知识点改为陈述句
- 50% 概率修改关键词制造错误版本
- 如将"必须"改为"可以"，"增加"改为"减少"

### 题目数据结构
```javascript
{
  id: "hash_string",           // 唯一ID
  course_id: "mit-14-01-...",  // 课程ID
  lesson_id: "L01 导论...",     // 课时ID
  kp_text: "原始知识点文本",     // 关联的知识点
  type: "single",               // single | multiple | truefalse
  question: "题干文本",          // 题目
  options: ["选项A","选项B","选项C","选项D"],
  correct_answers: [0],          // 正确答案索引数组
  explanation: "解析文本",       // 答案解析
  difficulty: 3,                // 难度 1-5
  variant: 2                    // 变形编号
}
```

## 自适应出题算法（QuizEngine）

### 出题比例
```
课时测验 50题 = 30单选 + 10多选 + 10判断
  ├── 80% (40题) 验证已掌握（level>=3）
  └── 20% (10题) 推新/弱项（level<3 或 forgotten）
```

### 题目选择逻辑

1. **收集候选题**：
   - 从题库中获取该课时/课程的所有题目
   - 按知识点掌握度分为"已掌握池"和"新/弱项池"

2. **80% 验证题**：
   - 从"已掌握池"中随机选
   - 同一知识点不连续出原题（从变形中随机选）
   - 优先选 `next_review <= now` 的知识点

3. **20% 推新题**：
   - 从"新/弱项池"中随机选
   - 优先选从未做过的知识点（level=0）

4. **补充机制**：
   - 如果已掌握题不足，从新题池补充
   - 确保题目总数始终达标

## SM-2 间隔重复算法（MasteryManager）

### 掌握度等级
```
level 0: 未学    → 间隔: 立即
level 1: 初学    → 间隔: 1天
level 2: 接触    → 间隔: 3天
level 3: 熟悉    → 间隔: 7天
level 4: 掌握    → 间隔: 21天
level 5: 精通    → 间隔: 60天
```

### 升降级规则

| 事件 | 操作 |
|------|------|
| 答对 | `consecutive_correct++`，如果 `consecutive_correct >= 3` → `level++`，重置计数 |
| 答错 | `level -= 2`（最低0），`consecutive_correct = 0` |
| 曾掌握(level>=3)答错 | `forgotten = true`，`level -= 2` |
| 升级到 level>=3 | `forgotten = false` |

### 间隔更新
```javascript
next_review = now + INTERVALS[level]
```

升级时，间隔指数增长：1天 → 3天 → 7天 → 21天 → 60天

## Canvas 特效系统（EffectsEngine）

| 场景 | 效果 | 持续 |
|------|------|------|
| 满分（100分） | 金色粒子爆炸 + "PERFECT"文字 | 3秒 |
| 连续5次满分 | 彩虹粒子 + 烟花 + "MASTERED"文字 | 5秒 |
| 课时满分 | 蓝色粒子 + 课节名弹出 | 2.5秒 |
| 期末考满分 | 全屏粒子雨 + "CHAMPION"文字 | 4秒 |
| 课程连续5次满分 | 金色背景闪烁 + 奖杯动画 + "LEGENDARY" | 5秒 |
| 分数下降 | 温柔灰色动画（不打击信心） | 2秒 |

所有特效使用 Canvas 2D API，通过 `requestAnimationFrame` 驱动，完成后自动销毁 Canvas 元素释放内存。

## 数据持久化

### localStorage Key 规范
```
quiz_{courseId}_{lessonId}_state
```

示例：
```
quiz_mit-14-01-microeconomics_L01 导论：经济学思维与供需模型_state
```

### 存储内容
```json
{
  "知识点文本哈希": {
    "level": 3,
    "consecutive_correct": 1,
    "last_review": 1785237000000,
    "next_review": 1785841800000,
    "history": [
      {"date": 1785237000000, "correct": true, "was_new": true}
    ],
    "forgotten": false
  }
}
```

### 注意事项
- 每个课时独立存储，避免单 key 过大
- 存储失败时（空间不足）会输出警告但不中断测验
- 数据不会自动清理，长期使用可能需要手动清理
